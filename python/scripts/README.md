# 🐍 Python Scripts

This folder contains reusable Python scripts created for the E-Commerce Sales & Profit Analytics project.

## 📂 Scripts

### customer_segmentation.py
Creates customer-level RFM-style metrics and assigns customers to business-oriented segments such as At Risk, Regular Customers, and Champions.

### data_cleaning.py
Contains reusable data-cleaning and preparation logic used to transform raw datasets into analysis-ready data.

### data_validation.py
Performs automated validation checks for dataset structure, data types, missing values, duplicates, and basic data quality.

## 🛠️ Tools Used

- Python
- Pandas
- NumPy

## 📌 Purpose

The scripts separate reusable data-processing logic from the exploratory Jupyter notebooks, making the project easier to maintain and reproduce.
