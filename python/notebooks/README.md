# 🐍 Python Analysis Notebooks

This folder contains the Jupyter notebooks used for the E-Commerce Sales & Profit Analytics project.

## 📓 Notebooks

### 01_data_validation.ipynb
Performs initial data validation and checks the structure, quality, missing values, and basic consistency of the source datasets.

### 02_eda.ipynb
Performs Exploratory Data Analysis (EDA) to understand sales, orders, customers, products, and delivery patterns.

### 03_customer_analysis.ipynb
Performs customer-level analysis and RFM-style segmentation using Recency, Frequency, and Monetary Value.

### 04_statistical_analysis.ipynb
Performs statistical analysis to support business insights and identify important patterns in the e-commerce data.

## 🛠️ Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📌 Purpose

These notebooks document the analytical workflow from raw data validation through exploratory analysis, customer segmentation, and statistical analysis.
