# 📂 Raw Data

The project uses the **Brazilian E-Commerce Public Dataset by Olist**.

The original dataset is not stored directly in this GitHub repository because some source CSV files exceed GitHub's standard web-upload file-size limit.

## 📥 Dataset Source

Download the original Olist dataset from:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## 📄 Main Source Files

The Power BI and Python workflows use source files including:

- `olist_orders_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_customers_dataset.csv`
- `olist_products_dataset.csv`
- `olist_sellers_dataset.csv`
- `product_category_name_translation.csv`
