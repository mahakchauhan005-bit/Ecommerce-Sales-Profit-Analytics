# 🗄️ SQL Analytics and Database Scripts

This folder contains the SQL scripts developed for the E-Commerce Sales & Profit Analytics project.

## 📂 Scripts

- `01_Create_Database.sql` → Database and table creation
- `02_Insert_Data.sql` → Data insertion
- `03_Business_Questions.sql` → Business analytics queries
- `04_Views.sql` → SQL views for reusable analysis
- `05_Stored_Procedures.sql` → Stored procedures
- `06_Triggers.sql` → Database triggers
- `07_Indexes.sql` → Indexing and query-performance optimization
- `08_Transactions.sql` → Transaction and rollback operations
